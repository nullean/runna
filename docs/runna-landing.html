C# or F#.
Then run it.

The same three targets either way: test needs build, which needs clean. It requires .NET 11.

build.cs
#!/usr/bin/env -S dotnet run --
#:package Nullean.Runna@0.1.0
#:property GenerateDocumentationFile=true
#:property NoWarn=CS1591
using Nullean.Runna;
using static Nullean.Runna.Shell;

var app = new RunnaApp<Target>("build");

app.Bind(t => t.Value switch
{
    Clean => app.Target(() => Exec("dotnet clean")),
    Build => app.Target([new Clean()], () => Exec("dotnet build")),
    Test  => app.Target([new Build()], () => Exec("dotnet test")),
    _ => throw new InvalidOperationException($"unmapped target {t.Value}")
});

return await app.RunAsync(args);

/// <summary>Delete build output</summary>
record Clean;
/// <summary>Build the solution</summary>
record Build;
/// <summary>Build, then run the tests</summary>
record Test;

union Target(Clean, Build, Test);

A file-based app is enough: build.cs next to your solution, run with dotnet run build.cs or straight from the shell.

build/Program.fs
open Nullean.Runna.Fs
open Proc.Fs

type Target =
    /// Delete build output
    | Clean
    /// Build the solution
    | Build
    /// Build, then run the tests
    | Test

[<EntryPoint>]
let main argv =
    let app = RunnaApp<Target>("build", None)

    app.Bind <| function
        | Clean -> target [] { sh $"dotnet clean" }
        | Build -> target [Clean] { sh $"dotnet build" }
        | Test  -> target [Build] { sh $"dotnet test" }

    app.RunAsync(argv).GetAwaiter().GetResult()

F# targets live in a small project, say build/build.fsproj with GenerateDocumentationFile on, run with dotnet run --project build --. A case you forget in Bind is a compiler warning.

The package READMEs cover the full DSL: Nullean.Runna for C# and Nullean.Runna.Fs for F#.
